# Japón 2027

Single-page itinerary for a three-week train trip around Japan (7–28 May 2027), published as a
static site at https://viaje-japon-2027.onrender.com.

## Stack

- [Astro](https://astro.build) 7, static output, one page (`src/pages/index.astro`). No UI
  framework: behavior lives in small TypeScript modules under `src/scripts/` (theme toggle with
  View Transitions, day rail, reveal, countdown, lazy art, route map).
- Tailwind CSS 4 via `@tailwindcss/vite`; design tokens and rules in `src/styles/index.css`.
- MapLibre GL 6 with OpenFreeMap tiles, loaded only when the map scrolls into view.
- Trip content in `src/data/` (plain TypeScript, rendered at build time).
- Isometric SVG art generated by `tools/art/` into `src/features/landing/{iso,hero-art}/*.markup.ts`
  (see `tools/art/README.md`).
- Self-hosted, subset fonts (Shippori Mincho, Zen Kaku Gothic New) generated by `tools/fonts/build.mjs`
  into `public/fonts/`.

## Requirements

- Node 26 LTS (`.node-version`; Astro needs ≥ 22.23.4).
- pnpm 12 (pinned in `packageManager`).

## Scripts

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server |
| `pnpm build` | Font subsets (no-op if the text is unchanged) → `astro check` → `astro build` into `dist/` |
| `pnpm preview` | Serve `dist/` |
| `pnpm check` | Type check (`astro check`) |
| `pnpm lint` | ESLint |
| `pnpm fonts` | Regenerate font subsets only |
| `node tools/art/build-all.mjs [--check]` | Regenerate the isometric art (or verify it is reproducible) |

## Deploy

Render static site: build command `pnpm install --frozen-lockfile && pnpm build`, publish
directory `dist`.
